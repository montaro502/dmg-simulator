# RO ダメージ計算ツール

ラグナロクオンライン (RO) のダメージ計算機です。物理攻撃と魔法攻撃の両方に対応しています。

## 機能

- 🎯 **物理・魔法攻撃対応** - 両方の攻撃タイプのダメージを計算
- 📊 **詳細な修正値対応** - カード効果、属性修正、サイズ補正に対応
- 🎮 **使いやすいUI** - シンプルで直感的なインターフェース
- 📱 **レスポンシブ対応** - モバイルデバイスにも対応

## 開発

### 必要な環境

- Node.js 18 以上
- npm または yarn

### セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build

# ビルド結果のプレビュー
npm run preview
```

開発サーバーは `http://localhost:5173` で起動します。

## ビルド

```bash
npm run build
```

`dist` フォルダに本番用ファイルが生成されます。

## デプロイ

このプロジェクトは GitHub Pages に自動デプロイするよう設定されています。

main ブランチへのプッシュで自動的にデプロイされます。

### 手動デプロイ

```bash
npm run build
# dist フォルダが生成されたら、GitHub Pages の設定で dist フォルダをソースとして選択
```

## 技術スタック

- **React 18** - UI フレームワーク
- **TypeScript** - 型安全性
- **Vite** - ビルドツール
- **CSS 3** - スタイリング

## 注意

このツールで計算されたダメージは概算値です。実際のゲーム内ダメージと異なる場合があります。
